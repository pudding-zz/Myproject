# 角色扮演：状态刷新 / 上下文截断 / 删会话

日期：2026-09-01

## 本次补齐

1. **AI Bean 理顺**：入库 `AiClientConfig` + `MockAiClient`；`DeepSeekAiClient` 去掉 `@Component`，仅由配置按 Key 创建。
2. **上下文截断**：`ai.history-max-messages`（默认 24）截断 roleplay / 穿书聊天喂给模型的历史。
3. **刷新当前状态**：`POST /api/roleplay/sessions/{id}/status/refresh`  
   - 对用户：按钮「刷新当前状态」  
   - 对内：AI 结算 JSON → 合并写 status，可选 healthPatch  
   - 无 Key 时 Mock 返回演示 life 四块
4. **删会话**：`DELETE /api/roleplay/sessions/{id}`，级联清 messages / health / status。

## 配置

```yaml
ai:
  history-max-messages: 24   # 或环境变量 AI_HISTORY_MAX_MESSAGES
```

## 前端

- 有会话时显示「刷新当前状态」「删除会话」
- 刷新成功后重载生理/状态面板，并用横幅展示 `note`

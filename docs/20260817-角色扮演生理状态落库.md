# 角色扮演：生理记录 / 角色状态落库

日期：2026-08-17  
范围：按 **roleplay 会话** 持久化；读写 CRUD（全量 PUT）；不依赖 AI Key。

## 表

### `roleplay_health_records`

| 列 | 说明 |
|----|------|
| session_id + day (1–31) | 唯一；一日一行 |
| cal / heart / count / duration | 数值，默认 0 |
| trigger_text / scene / thought | 文案；API JSON 中字段名为 `trigger` |

汇总 `summary` 在 GET 时计算，不落库。

### `roleplay_session_status`

| 列 | 说明 |
|----|------|
| session_id | 唯一，一会话一份 |
| payload | JSON：blocks / intimacy / life / favorability / favorOs / forum / theater / misc / access |

创建会话时写入**空骨架**（各数组空、theater/access 空对象），不写入 demo 长文。

## 接口

前缀：`/api/roleplay`（context-path=`/api`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/sessions/{id}/health` | `{ available, summary, records }` |
| PUT | `/sessions/{id}/health` | body `{ records: [...] }` 全量替换 |
| GET | `/sessions/{id}/status` | `{ available: true, ...payload 字段展开 }` |
| PUT | `/sessions/{id}/status` | body 为状态对象（与 demo 键一致），全量写入 |

旧会话若尚无 status 行：GET 仍返回空骨架；PUT 会创建行。

## 字段对应

- DB `trigger_text` ↔ JSON `trigger`
- 前端折叠态不入库

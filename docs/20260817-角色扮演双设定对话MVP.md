# 2026-08-17：角色扮演玩法（双设定对话）MVP

## 产品

新增独立玩法：**AI 角色对话**（与穿书并行）。

- 用户填写 AI 身份 + 玩家身份（名字/性别/身份/性格/关系）与可选场景
- 创建会话后 AI 先开场，再进入多轮对话
- 穿书链路（底本 / advance / 偏离）不改动

后续将补：角色状态、生理记录、亲密记录（前端已留折叠面板占位）。

## 分支

`feature-20260817-角色扮演`（前后端同仓同分支）

## 后端 API（context-path `/api`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/roleplay/sessions` | 会话列表 |
| POST | `/roleplay/sessions` | 创建会话（可开场白） |
| GET | `/roleplay/sessions/{id}` | 会话详情 |
| GET | `/roleplay/sessions/{id}/messages` | 消息历史 |
| POST | `/roleplay/sessions/{id}/messages` | 发送并返回 AI 回复 |
| GET | `/roleplay/sessions/{id}/status` | **占位**，后续角色状态 |
| GET | `/roleplay/sessions/{id}/health` | **占位**，后续生理/亲密 |

表：`roleplay_sessions`、`roleplay_messages`（JPA `ddl-auto` 自动建）。

## 前端

- 路由：`/roleplay`、`/roleplay/:id`
- 视图：`frontend/src/views/RoleplayView.vue`
- 首页增加「进入 AI 角色对话」入口

## 本地验证

1. JDK 17 启动后端（需 DeepSeek key，或已有 MockAiClient 配置）
2. `cd frontend && npm run dev`
3. 打开首页 → 进入 AI 角色对话 → 开始对话
